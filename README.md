One line, at most 200 characters: the funniest excuse an AI agent could
offer after it fails a task.

> I outsourced the task to a smarter version of me, and he ghosted us both.

`main.ts` writes that line to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no subprocesses.
